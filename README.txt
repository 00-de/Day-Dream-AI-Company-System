SDayDream Music Studio — Phase 1.1（制作画面リニューアル版）

【中身】v2.1（Phase 3：AI連携版／Claude対応）
index.html … 画面
app.js     … 作曲・編曲・音源・書き出しエンジン

【Vercelに上げる】
1. この2ファイルを同じフォルダに入れる
2. Vercel にフォルダごとドラッグ&ドロップ
3. Framework Preset は「Other」
4. デプロイ後 Ctrl + Shift + R で再読み込み

【PCで開く】
index.html を右クリック →「プログラムから開く」→ Chrome / Edge
（app.js を同じフォルダに置いたままにしてください）

【画面の使い方】
・左端の縦列 … 今のトラック。押すと制作設定が開きます
・中央左 LYRICS … 「書く」で歌詞入力、「同期」で再生に合わせて光ります
・中央右 SESSION … BPM・キー・拍子、コード進行、トラックミキサー
・右 REALTIME … 可視化。下は 波形／楽譜／MV の切り替え
・下 TIMELINE … 曲構成。押すとその位置へ飛びます
・PLAY / STOP / REC（RECはWAV書き出し）

【メンバー・楽器の選び方】
画面左上の「⚙ 制作設定」、または中央の「⚙ 制作設定を開く」を押すと
右から設定パネルが出ます。ここでプリセット・メンバー・バンド・
オーケストラ・マンドリンを選び、「この内容で決定」で閉じます。
選んだ内容は中央の一覧と、左端のトラック列に出ます。

【音質と時間】
中央の「音質」で書き出し時間が変わります。
　下書き … 22kHz・音数半分・残響なし。標準の 5〜8 倍速い。まずこれで確認
　標準   … 44.1kHz・残響あり。仕上げ用
　高音質 … 残響を長く。時間が最もかかります
生成中は進捗％と経過秒数が出ます。数字が動いていれば正常に処理中です。

【SUNOプロンプト画面】
上部メニューの「SUNO」を開きます。
1. 曲名・テーマ・入れたい言葉・ジャンル・雰囲気・言語を入れる
2. BPM・キー・調・拍子を決める
3. 歌唱編成（ソロ／デュエット／トリオ／フォース／全員）を選ぶと
   人数ぴったりまで自動で埋まります。個別に入れ替えも可能
   先頭の人がメインボーカル、サビは選んだ全員のユニゾンになります
4.「プロンプトと歌詞を作る」を押す
5. 出てきた5つをコピーして SUNO のカスタムモードへ
   ・Suno Style Prompt → Style欄
   ・Lyrics            → Lyrics欄
   ・Exclude Styles    → Exclude Styles欄
   ・DayDream＋専用プロンプト → 詳細指示や記録用
   ・Title案 → 押すと曲名に反映

「歌詞だけ作り直す」で何度でも引き直せます。

【Phase 3 / AIアシスト】
SUNO画面の「AI アシスト」から使えます。
　歌詞をAIで書く … テーマと編成から構成タグ付きの歌詞を書き下ろし
　歌詞を推敲     … 語呂・助詞・字余り・重複を直す（見出しは保持）
　タイトル案     … 8案
　スタイル文を整える … Suno の Style 欄用の英文を整形
　よみがなを付ける   … 歌声合成ソフトに渡す前の下ごしらえ
　AI社員レビュー … Takagi / Ota / Nakao / Shun の4人が講評

APIキーの入れ方は「環境変数の入れ方.txt」を見てください。
未設定でも、これまでの下書き生成と作曲機能はそのまま動きます。
